隐私与安全

更新日期：2026 年 7 月 30 日

Windows 本地版

SMTP 配置、账号、密码、邮件内容和测试结果只在当前电脑的进程内存中处理。客户端不会把这些数据写入配置文件，也不会发送给本项目运营方。浏览器只连接本机的 127.0.0.1 服务。

Cloudflare 在线版

提交在线测试时，SMTP 配置、账号、密码和邮件内容会通过 HTTPS 发送到 Cloudflare Worker，再由 Worker 与目标 SMTP 服务器建立连接。在线版不会主动持久化请求体、密码、邮件内容或测试结果，也不会在应用日志中记录 SMTP 认证命令。

Cloudflare 可能根据其基础设施政策处理网络与安全日志。敏感账号、生产账号、自签名证书、内网服务器或受合规要求约束的邮件，请使用 Windows 本地版。

在线服务保护

  • 在线版仅允许公网域名和 465/587 标准加密端口。
  • DNS 解析到私网、保留或文档地址的目标会被拒绝。
  • 按来源限制测试频率，并限制请求与字段大小。
  • 测试成功只表示 SMTP 服务器接受邮件，不表示最终进入收件箱。

投递质量检测

启用投递质量功能后，系统会通过 mail-tester 官方 API 创建与查询测试报告。用户发送到临时地址的邮件由 mail-tester 接收和分析，并受其隐私政策与服务条款约束。本项目只保存浏览器当前会话中的短期签名令牌；完成报告在 Cloudflare Cache 中最多缓存 5 分钟。

开源与问题报告

源代码公开后，可通过页面顶部的 GitHub 链接审计实现或提交安全问题。部署者应在 GitHub 仓库中配置安全报告渠道，并避免在公开 Issue 中粘贴真实 SMTP 密码、授权码或完整邮件内容。
