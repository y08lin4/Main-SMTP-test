在线测试

提交测试时，SMTP 配置、账号、密码和邮件内容会通过 HTTPS 发送到 Cloudflare Worker，再由 Worker 与目标 SMTP 服务器建立连接。服务不会主动持久化请求体、密码、邮件内容或测试结果，也不会在应用日志中记录 SMTP 认证命令。

Cloudflare 可能根据其基础设施政策处理网络与安全日志。请勿使用生产账号、长期有效的高权限凭据或受合规要求约束的邮件内容。

浏览器保存

使用“保存此浏览器”时，浏览器仅在本机保存 SMTP 服务器、端口、加密方式、登录账号、发件人地址和发件人显示名，方便下次填写。密码、收件人、主题和邮件内容不会写入浏览器存储。

保存的信息可被同一浏览器配置文件的使用者读取；在公用设备上请勿保存，并可随时使用“清除已保存”删除。

在线服务保护

  • 仅允许公网域名和 465/587 标准加密端口。
  • DNS 解析到私网、保留或文档地址的目标会被拒绝。
  • 按来源限制测试频率，并限制请求与字段大小。
  • 测试结果仅说明 SMTP 服务器是否接受本次提交。

开源与问题报告

源代码公开后，可通过页面顶部的 GitHub 链接审计实现或提交安全问题。部署者应在 GitHub 仓库中配置安全报告渠道，并避免在公开 Issue 中粘贴真实 SMTP 密码、授权码或完整邮件内容。
